## 🌟 Project Overview
This project explores the critical differences between **Exploratory Data Analysis (EDA)** and **Machine Learning (ML)** in a business context. Using a comprehensive dataset of 100,000 e-commerce transactions (`ecommerce_sales_data.csv`), we analyze historical sales patterns and build predictive models to enhance business decision-making.
